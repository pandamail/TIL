## 오늘 배운 것

### [Algorithm] DFS — 미로1 (1226번)

오늘 처음으로 DFS/BFS라는 알고리즘 유형을 접했다.

- **DFS**: 분신(그림자)을 한 방향으로 파견해서 막히면 이전 갈림길로 되돌아오는 방식 (Backtracking)
- **BFS**: 사방으로 물결처럼 동시에 퍼져나가는 방식

DFS 구현 구조:

```python
dx = [0, 1, 0, -1]  # 우·하·좌·상
dy = [1, 0, -1, 0]

def dfs(x, y):
    for i in range(4):
        nx, ny = x + dx[i], y + dy[i]
        if 0 <= nx < 16 and 0 <= ny < 16:
            if matrix[nx][ny] == 3:   # 도착점이면 성공
                return 1
            elif matrix[nx][ny] == 0: # 통로면 방문 처리 후 재귀
                matrix[nx][ny] = 1    # 발자국 (무한루프 방지)
                if dfs(nx, ny) == 1:
                    return 1
    return 0
```

**🚨 오늘 실수 2가지**

1. **범위 조건은 `and`**: `or`를 쓰면 하나만 만족해도 통과되어 범위 밖을 읽음
2. **입력 포맷 함정**: 이 문제는 전체 T를 안 주고 10회 고정 — `for _ in range(10)` 후 루프 안에서 케이스 번호를 직접 받아야 함

### [Logic] 마름모 슬라이싱 — 농작물 수확 (2805번)

N×N 배열에서 정중앙을 기준으로 마름모 모양의 합을 구하는 문제.  
`center = N // 2`로 중앙 인덱스를 잡고, `start`와 `end`를 벌렸다 좁히는 방식으로 해결했다.

```python
center = N // 2
start, end = center, center

for i in range(N):
    ans += sum(matrix[i][start:end + 1])
    if i < center:
        start -= 1; end += 1  # 벌리기
    else:
        start += 1; end -= 1  # 좁히기
```

**🚨 데이터 파싱 함정**

숫자가 공백 없이 붙어서 들어올 때 `.split()` 쓰면 통째로 묶임.  
→ `list(map(int, input()))` 으로 한 글자씩 쪼개야 함

### [Structure] set()으로 스도쿠 검증 — 1974번

```python
# 세로 열 한 줄 추출
col = [matrix[i][j] for i in range(9)]

# 3×3 박스 시작점: 0, 3, 6
for i in range(0, 9, 3):
    for j in range(0, 9, 3):
        box = [matrix[i+x][j+y] for x in range(3) for y in range(3)]
        if len(set(box)) != 9:
            return 0
```

`len(set(배열)) != 9` — 중복이 없으면 1~9 모두 있다는 뜻.  
내부 루프 변수 이름(x, y)을 바깥 루프(i, j)와 겹치게 쓰면 덮어써서 버그 발생.
