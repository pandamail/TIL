# 행사 개최형 사업 — 사업 생애주기

- **작성일**: 2026-07-27
- **배경**: 여러 이해관계자를 초청해 공식 행사(창립총회·설명회·세미나 등)를 여는 사업을 처음부터 끝까지 진행하며 정리한 흐름. 특정 행사 하나에 국한되지 않고, 대상자 조율이 필요한 행사 전반에 공통 적용된다.

## 전체 흐름

```mermaid

    C --> D[공문 + 의결문서 발송]
```

## 단계별 메모

### 1. 개최(안) 초안 작성
문서 구성 순서는 **개요 → 구성 → 주요 기능 → 안건/프로그램 목록 → 향후 일정**을 따른다.
주의할 점: 아직 확정되지 않은 사안(예: 세부 운영계획)을 계획(안) 문서에 기정사실처럼 써넣지 않는다. "안"이라는 단어가 붙은 문서는 말 그대로 확정 전 상태여야 한다.

### 2. 붙임파일 관리
상급자가 넘겨준 템플릿·붙임파일을 그대로 갖다 쓰지 않는다. 반드시 내용을 읽고, 추가하거나 빼야 할 부분이 있다고 판단되면 먼저 들고 가서 확인한 뒤 반영한다. 붙임파일은 본문과 분리해서 개별 파일로 관리한다.

### 3. 결재 상신
결재라인은 **연구원 → 팀장 → 본부장** 순서를 따른다. 이 문서 하나에 정해진 결재라인이 아니라, 보고서식 문서 전반에 적용되는 기본 패턴이다.

### 4. 대상자 일정 조율
참여 대상자에게 개별 연락(설문/전화)으로 가능 일자를 조사하고, 날짜가 확정된 이후에 장소를 선정한다. **날짜 확정 → 장소 확정** 순서가 바뀌면 장소 쪽에서 재작업이 생긴다.

### 5. 공문 + 관련 문서 발송
날짜·장소가 확정되면, 행사가 어떤 내용으로 진행되는지 설명하는 공문을 관련 문서(필요 시 의결문서 등)와 함께 결재받아 대상자에게 메일로 발송한다.

### 6. 결과보고
행사 종료 후 진행 결과, 논의된 내용, 후속 조치가 필요한 사항 등을 정리한 결과보고서를 작성하고 결재를 올려 마무리한다.

## 배운 점

- 이런 유형의 사업은 **초안 하나로 끝나지 않고 최소 2~3회 이상 수정본이 오간다.** 처음부터 완벽한 안을 만들려 하기보다, 빠르게 초안을 만들고 피드백 루프를 도는 게 더 빠르다.
- "일정 조율 → 확정 → 장소 → 공문 → 행사 → 결과보고"라는 순서 자체가 이 유형 사업의 표준 골격이라, 다음에 비슷한 성격의 행사를 맡으면 이 순서를 그대로 체크리스트로 쓸 수 있다.
