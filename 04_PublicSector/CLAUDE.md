# CLAUDE.md — 04_PublicSector 운영 가이드

## 폴더 목적

경남테크노파크 디지털혁신거점팀 근무(2026.07.06~) 중 익히는 **공공기관 사업관리 프로세스/패턴**을 기록하는 공간이다.
특정 사업의 실제 내용이 아니라, "이런 유형의 업무는 이런 흐름으로 진행된다"는 재사용 가능한 지식만 남긴다.
원본 업무 자료(기안서, 견적서, 정산 문서 등)는 로컬 `문서/` 폴더에만 두고, 여기로는 절대 그대로 옮기지 않는다.

## 기록 대상

- **기안서 프로세스**: 기안서 유형별 흐름과 결재라인 (예: 사업 공고 → 접수 → 요건검토 → 결재 → 시행 순서, 붙임파일 표기 규칙 등 실무 관례)
- **사업 생애주기**: 사업 유형별로 공고~정산까지 몇 단계를 거치는지, 어떤 서류가 언제 오가는지
- **반복 행정 절차**: 출장비, 초과근무수당, 사업비 집행 등 매달 반복되는 정산 프로세스
- **이해관계자 조율 패턴**: 몇 개 부서/기관과 협의가 필요한지, 순서와 소요 기간 감각
- **용어 정리**: 공공기관·사업관리 특유 용어와 약어
- **주간/월간 업무보고**: 실제 보고서 내용이 아니라, 그 주/그 달에 어떤 "종류"의 업무를 했는지 요약 (decisions 문서의 coordinator 자기진단을 검증하는 데이터로도 활용)

## 하위 구조 (문서가 쌓이면서 필요할 때 생성)

```
04_PublicSector/
├── 기안서_프로세스/    # 기안서 유형별 흐름, 결재라인 패턴
├── 사업관리/           # 사업 유형별 생애주기(공고~정산)
├── 정산_행정/          # 출장비/초과근무/사업비 등 반복 행정 절차
└── 업무보고/           # 주간/월간 업무 요약(익명화)
```

없는 하위 폴더를 미리 다 만들지 말 것. 첫 문서가 생길 때 그 카테고리 폴더를 만든다.

## 절대 포함 금지

| 항목 | 이유 / 대체 표현 |
|---|---|
| 기업명·상호명·협력업체명 | "OO 지원사업 참여기업", "행사장 대관 업체" 등 일반명사로 |
| 금액·견적가·예산 수치 | 구체적 숫자 없이 "예산 규모에 맞춰 비교 견적을 받았다" 정도로 |
| 개인 실명 (동료·상사·외부인사 전원) | 직책/역할로만 지칭: "담당 선임", "센터장", "위원" |
| 특정 사업의 심사·평가·선정 결과 | 미공개 행정정보. 언급 자체를 피한다 |
| 미공개 기안서·의결서·회의록 원문 텍스트 | 절대 복사 붙여넣기 금지. 프로세스만 서술 |
| 위원회/자문단 명단, 연락처, 소속 | 전면 제외 |
| 계약·입찰 세부 조건 | 전면 제외 |

## 포함 가능

- 문서 종류와 그 문서가 왜 필요한지에 대한 일반화된 설명
- 프로세스 단계 순서, 소요 기간 감각 ("보통 접수 후 검토에 며칠 정도 걸린다" 등)
- 실수하고 배운 것의 "패턴"만 (구체적 사건은 지우고 체크리스트 형태로)
- 용어·약어 정리
- 조율/커뮤니케이션에서 통했던 방식, 안 통했던 방식

애매하면 추측해서 쓰지 말고 먼저 사용자에게 확인한다 (루트 `CLAUDE.md`의 No Silent Creation 원칙과 동일).
